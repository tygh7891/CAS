# ROS 2부터 CAS FMS까지

목표는 관제 화면에서 작업을 등록한 뒤 **서버가 통행권을 결정하고, Worker가 Nav2에 이동·회전을 전달하는 흐름**을 직접 설명하는 것이다. 처음에는 Python과 화면 속 거북이로 같은 개념을 연습한다. 각 단계의 확인 문제를 통과한 뒤 다음 단계로 이동한다.

| 순서 | 실습 | 어디서 | 통과 기준 |
|---|---|---|---|
| 01 | [터미널·Python·JSON](01-PYTHON-TERMINAL/README.md) | Mac 또는 Ubuntu | 입력 숫자 하나를 바꾸고 어느 출력이 달라질지 예측한다. |
| 02 | [ROS 2 노드·토픽·서비스·액션·도메인](02-ROS2/README.md) | 강의실 Ubuntu + Jazzy | 같은 도메인에서 수신을 확인하고, 서비스 응답과 액션 결과를 구분한다. |
| 03 | [Pinky 센서·TF·RViz](03-PINKY/README.md) | Mac 계산 예제 → Ubuntu TF → Pinky 읽기 | 프레임 기준으로 위치를 읽고, 위치·방향·라이다 거리의 차이를 설명한다. |
| 04 | [SLAM·위치 추정·Nav2](04-SLAM-NAV2/README.md) | Mac 지도 읽기 → Ubuntu 시뮬레이션 | 지도·초기 위치·목표·실행 결과를 구분하고 목표 한 건을 관찰한다. |
| 05 | [한 대 왕복에서 두 대 통행권까지](05-FMS/README.md) | Mac 또는 Ubuntu | 통행권이 이탈 관측 뒤 넘어가는 이유를 로그와 실제 소스에서 설명한다. |

**지금 시작할 일**은 01의 `pose_report.py`를 실행하고 `x` 값을 바꿔보는 것이다. 강의실에서는 02의 통신 실습을 먼저 하고, 장비가 없을 때는 03의 좌표 계산, 04의 지도 읽기, 05의 로컬 모의 실습을 이어서 할 수 있다. 03~05의 선택 실습은 필수 흐름을 설명한 뒤에 살펴본다.

## 실행 경로

터미널에서 CAS 저장소 루트로 이동한 다음 아래 명령을 실행한다. 각 실습의 상대 경로 명령은 이 학습 폴더를 기준으로 한다. 실습용 ROS 워크스페이스나 생성물은 별도 경로를 사용한다.

```bash
cd pinky_cas_fms/docs/05-ROS2-LEARNING
python3 --version
```

로컬 Python 예제는 표준 라이브러리를 사용한다. 출처 확인 도구는 Python 3.11 이상이 필요하다. ROS 예제는 Ubuntu의 시스템 Python과 Jazzy 환경을 사용한다. 여러 터미널을 사용하는 실습에는 각각 필요한 초기 명령을 적었다.
