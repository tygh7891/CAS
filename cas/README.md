# CAS 응용 프로그램

기존 Pinky Pro ROS2 패키지는 저장소 루트에 유지하고, CAS 응용 코드는 이 폴더에 작성합니다.

- `shared/`: 메인·예비 구현이 공유할 설정과 명령·상태 규약
- `primary/`: 팀원의 메인 서버·GUI 구현을 위한 자리
- `backup/`: 예비 서버·GUI·공유존 제어 구현

현재는 폴더 구조와 안내만 준비했습니다. 실행 가능한 서버·GUI는 아직 없습니다. API, 공통 설정 형식과 제어권 인계 절차는 A1 팀 협의에서 확정합니다. 메인·예비 서버를 동시에 로봇 제어에 사용하지 않습니다.
