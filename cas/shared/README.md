# CAS 공통 연결 규칙

사용자가 2026-11-10에 A1 권장안으로 진행하기로 했음을 확인했습니다. 합의된 설계와 구현 완료는 구분합니다.

| 항목 | 채택한 기준 | 현재 상태 |
|---|---|---|
| 구성 | GUI → 중앙 서버 → PC의 로봇별 Worker 두 개 | 전체 구성 통합 전 |
| 로봇 구분 | robot_1 / 도메인 14, robot_2 / 도메인 30. 기존 ROS 토픽 이름 유지 | 센서·A2 모의 분리 확인 |
| 프로그램 연결 | HTTP+JSON, GUI는 중앙 서버와만 통신 | API·포트·세부 스키마 구현 전 |
| 명령 | request_id·task_id·robot_id·command, NAVIGATE·SPIN·CANCEL, 등록 시나리오 요청 | 실물·HTTP 명령 계층 구현 전 |
| 중복 처리 | 같은 request_id 재실행 금지, 로봇당 활성 작업 하나 | 중앙 API 구현 전; A4는 예약 대기열 중복만 검사 |
| 상태 | task_state와 phase 분리, 회전 성공까지 전체 작업 완료로 표시 | A3·A4 내장 모의 구현 |
| 좌표 | map, m, rad, map_id 공통화. 지도 원점·방향·버전 검증 | 실물 지도 대기; 모의 좌표와 실물 odom은 별도 |
| 설정 | scenario.yaml을 공통 형식으로 사용하고 미확정 좌표로 실물 시작 차단 | 공통 설정 구현 전; 기존 scenario.mock.json은 내장 모의 전용 |
| 공유존 | 한 대만 허가, 요청 순서·동률 1번 우선, 전체 외형 이탈 확인 후 해제 | A3·A4 모의 검사 |
| 회전 | Nav2 Spin 우선, 한 바퀴 기본안 | 실물 각도·방향·속도·공간·판정값은 시험 후 확정 |
| 보고 주기 | 위치 5Hz 초기값, 위치 원본 1초 미갱신 시 허가·해제 보류, 배터리 약 5초 | A4 모의 1초 보호 구현; 실제 보고 계층 조정 전 |
| 취소·실패 | 취소 응답과 정지 확인 후 취소 완료, 불확실한 점유 유지, 자동 재출발 금지 | A4는 모의 즉시 정지 확인 가정, 실물 통합 전 |
| 제어권 | 메인·예비 단일 제어권, 정지·Goal 정리 후 수동 인계, 비활성 요청 거부 | 서버/Worker 제어권 기능 구현 전 |
| 기록 | JSONL 사건 로그, 기능 브랜치·PR 검토 | 로컬 로그·작업 브랜치 사용 중 |

원래 A1 공유 문서의 16개 항목이 상위 기준입니다. IP·개인 적용 기록은 로컬에 두며, 비밀번호·토큰은 저장소에 넣지 않습니다. 1차 완료 후 작업구역에서 대기하며 자동 복귀는 하지 않습니다.
