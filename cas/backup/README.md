# 예비 서버·GUI

작업 브랜치: `feature/backup-server-gui`

1차 목표: 로봇 1은 1→B, 로봇 2는 2→A로 주행하며 고정 공유존을 순차 통과하고 목적지에서 제자리 회전합니다.

개발 순서: A1 연결 규칙 합의 → 로봇별 명령 연결 준비 확인 → 작업 상태 흐름 → 공유존 모의 시험 → 서버·GUI → 실제 상태 수신 → 지도 완성 후 실물 통합.

현재 PC ~/CAS의 모니터·수정안과 로봇에 적용한 코드는 아직 이 브랜치에 포함하지 않았습니다. 별도 검토 후 가져옵니다. 2차 통신 단절·블락존과 3차 공유존 자동 생성은 1차 완료 후 진행합니다.
