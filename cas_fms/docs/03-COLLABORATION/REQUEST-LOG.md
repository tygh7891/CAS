## Gazebo에서 두 로봇 주행 검증

**[사용자 요청]** 팀원이 공유한 맵을 재사용해 Gazebo에서 핑키프로 두 대로 기존 FMS 교차로 시연을 재현한다. 수업에서 배운 Nav2를 활용하고, 시뮬레이션으로 검증할 수 있는 항목을 실물 적용보다 먼저 진행한다. [시연 실행 방법](../02-TESTING/LOCAL-DEMO.md#gazebo에서-핑키프로-두-대-시연)

## FMS 실물 연결 모드

**[사용자 요청]** FMS 소스를 노트북에 두고 실물 핑키프로에 연결하는 모드를 구현한다. 이번 단계에서는 로봇 주행 없이 노트북 내부에서 가능한 검증을 진행한다. [실물 연결 모드](../02-TESTING/REAL-MODE.md)

## ROS 2 실습 문서

**[사용자 요청]** 진행한 구현과 검증 결과를 정리하고, 노트북에서 가상 시연과 실물 읽기 전용 연결을 직접 따라 할 수 있는 절차를 작성한다. 관련 HTML 강의를 단계별로 연결하고 명령, 의미, 확인 결과를 중심으로 설명한다. [ROS 2 실습 문서](../05-ROS2-LEARNING/README.md)

## FMS 화면 개선과 Gazebo 시연

**[사용자 요청]** 시안에 맞춰 PyQt FMS 화면을 개선하고 두 로봇의 배터리를 표시한다. 정상 순차 통과, 위치 보고 중단·복구, 교차로 내 작업 취소를 각각 버튼으로 시작하며, 매번 두 로봇을 출발점부터 움직인다. 실물 주행 없이 Gazebo에서 검증한다. [실행 및 확인 방법](../02-TESTING/LOCAL-DEMO.md#시연-시나리오)

**[후속 요청]** 로봇 카드에서 배터리 잔량만 작게 표시하고, 수신이 끊겼을 때 상태를 알린다.

## 실물 핑키프로 읽기 전용 점검과 인계

**[사용자 요청]** 1번부터 두 로봇의 기존 노드를 실행해 라이다, 오도메트리, 배터리, 지도 위치를 FMS에서 확인한다. 로봇 파일을 복사하거나 수정하지 않고, 실물 주행 없이 지도·Nav2를 점검한다. 충전과 팀 사용 순서에 맞춰 노트북의 연결을 종료한다. [센서와 FMS 실습](../05-ROS2-LEARNING/03-PHYSICAL-READONLY-LAB.md) · [지도·Nav2와 인계](../05-ROS2-LEARNING/05-FIELD-NAV2-CHECK.md)

**[문서 이력]** 이전 학습 문서 이후의 GUI 개선, Gazebo 재시연, 실물 점검과 남은 작업을 실행 절차 및 검증 결과와 함께 반영했다.
