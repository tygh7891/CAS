# 로컬 가상 시연

[문서 홈](../README.md) · [팀 개발 기준](../04-ENGINEERING/README.md)

로컬 시연은 장윤호님이 공유한 기본 지도와 X자 진입 제한 마스크를 `cas_fms/maps/`에서 읽는다. `scenario.yaml`의 출발점·대기점·목적지·공유 Zone은 이 지도에서 고른 **가상 시연용 값**이다. 장비 연결에 쓸 좌표와 회전 조건은 실물 시험 단계에서 확인한다.

## 실행

`cas_fms/`에서 Python 3.12로 실행한다. 의존성이 갖춰진 환경에서는 마지막 명령으로 바로 창을 열 수 있다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m local_demo
```

**시연 시작**을 누르면 1번은 B로, 2번은 A로 이동한다. 지도와 로봇 카드에서 대기·통과·회전 상태를 확인한다. 두 로봇이 정지한 뒤 다시 누르면 출발점 1과 2로 초기화하고 새 시연을 시작한다.

가상 Worker 두 개는 로컬 HTTP 서버에 위치와 명령 결과를 보내고 다음 명령을 받는다. 이동은 공유 지도에 설정한 경유점 사이의 보간으로 재현한다. 검증 범위는 서버의 진입권·작업 상태와 GUI 동작이다.

## Gazebo에서 핑키프로 두 대 시연

ROS 2 Jazzy, Gazebo Harmonic, `ros_gz`, Nav2, `colcon`과 시스템 Python의 PyQt5·Flask·PyYAML이 설치된 PC에서 `cas_fms/`를 열고 실행한다.

```bash
./run_gazebo_demo.sh
```

Gazebo 창과 **CAS FMS · Gazebo** 창이 열린다. 버튼이 활성화되면 시연을 선택한다. 매번 두 모델을 출발점 1과 2로 옮기고 AMCL 위치와 정지를 확인한 뒤 주행을 시작한다. FMS 창을 닫으면 이 시연에서 띄운 프로세스도 종료된다. 화면 없이 HTTP로 시험하려면 `./run_gazebo_demo.sh --headless --port 18765`를 사용한다.

공유 `fleet_world_new`의 장애물 셀로 Gazebo의 충돌 공간을 구성하고, 원본 맵은 각 로봇의 MapServer와 AMCL에서 그대로 읽는다. `fleet_x_keepout_new`는 Nav2 진입 제한 마스크로 사용한다. Gazebo의 기본 시점은 맵을 위에서 내려다본다. 흰색 X자 영역은 주행 통로이고, 청회색 바닥은 진입 제한 영역이다. 기본 실행은 `gazebo_round_trip_scenario.yaml`을 사용한다. 두 가상 출발점은 마지막 회전 공간을 확보하도록 조정했다. 가상 ROS 2 도메인 114와 130은 로컬에서만 검색한다.

### 시연 시나리오

1. **교차로 왕복**. 서버는 교차로가 비어 있을 때 접근 중인 로봇에 진입권을 미리 준다. 진입권을 받은 로봇은 이동 목표를 유지하며 통과한다. 진입권이 없는 로봇이 경계에 가까워지면 속도 출력을 차단한다. 선행 로봇이 반대쪽으로 빠져나오고 진입권 회수를 확인하면 다음 로봇이 통과한다. 각 로봇은 목적지에서 180° 회전하고 복귀할 때 같은 진입권 규칙을 적용한다. 출발점에서 다시 180° 회전하고, 필요한 경우 방향을 미세 조정한다. FMS가 보고받은 위치가 출발 좌표에서 4cm 이내, 방향이 약 7° 이내이고 로봇이 정지했으면 완료한다.
2. **위치 보고 중단·복구** — 두 로봇이 대기점에 도착한 뒤, 교차로에 진입한 로봇의 위치 보고를 5초간 중단한다. 해당 로봇은 기존 이동 명령을 수행한다. 다른 로봇은 대기점에 머무르며, 서버는 새 위치 보고로 교차로 이탈을 확인한 뒤 다음 진입을 허용한다.
3. **교차로 내 작업 취소** — 두 로봇이 대기점에 도착한 뒤, 첫 로봇이 교차로 안에 들어오면 양쪽 작업을 취소하고 정지를 확인한다. 로봇이 교차로에 남아 있으면 진입권을 유지한다. 새 시연을 선택하면 두 로봇을 출발점으로 옮긴 뒤 초기화가 완료됐을 때 진입권을 비운다.

지도에서 로봇이나 오른쪽 카드 제목을 누르면 해당 경로가 강조된다. 교차로 패널은 진입권, 대기 로봇, 보류 사유를 표시한다. 최근 이벤트는 시연 시작부터의 경과 시간을 표시한다.

### 배터리와 센서

로봇 카드는 배터리 잔량을 작게 표시한다. 잔량이 15초 동안 갱신되지 않으면 **배터리 수신 중단**을 표시한다. 배터리 잔량을 받은 적이 없으면 **배터리 미수신**을 표시한다. 라이다, 오도메트리, 지도 위치의 수신 상태는 각각 표시한다.
